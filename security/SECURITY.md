# Política de Seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad:

1. **No** crees un issue público
2. Reporta a través de [GitHub Security Advisories](https://github.com/sis-inf/trazo/security/advisories) del repositorio
3. Incluye descripción detallada del problema y pasos para reproducirlo
4. Espera confirmación antes de divulgar públicamente

## Canal de contacto

Usa **[GitHub Security Advisories](https://github.com/sis-inf/trazo/security/advisories)** para reportar vulnerabilidades. Este es el canal privado preferido.

## Plazos de respuesta y divulgación

| Fase | Plazo |
|------|-------|
| Confirmación de recepción | 48–72 horas |
| Evaluación inicial | 7 días |
| Plazo de divulgación | 90 días (por defecto) |

- Si la vulnerabilidad se resuelve antes de los 90 días, la divulgación puede coordinarse anticipadamente.
- Si se necesita más tiempo, podemos acordar extensiones de mutuo acuerdo.

## Análisis de seguridad

Este proyecto ejecuta análisis automático de seguridad (CodeQL) en cada PR que se envía a la rama `main` y en cada push a `dev` mediante GitHub Actions.
