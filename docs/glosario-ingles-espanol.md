# Glosario Inglés–Español

| Término | Definición |
|---|---|
| callback | Función que se pasa como argumento a otra función para que sea llamada más tarde, normalmente en respuesta a un evento o al completar un paso de un método. |
| source map | Archivo que relaciona el código JavaScript generado con el código fuente original, útil para depuración. |
| sourcemap (configuración) | Opción de herramientas como Rollup que activa la generación de *source maps*. |
| sourceType | Configuración de ESLint o Babel que indica cómo debe interpretarse el código fuente (por ejemplo, como módulos ES). |
| trade-off | Compromiso entre dos decisiones técnicas donde mejorar un aspecto implica empeorar otro. |
| import | Palabra clave de JavaScript para traer funciones, clases o valores desde otro módulo. |
| export | Palabra clave de JavaScript para exponer funciones, clases o valores a otros módulos. |
| re-export | Acción de volver a exportar algo que fue importado desde otro módulo. |
| Error | Objeto nativo de JavaScript usado para representar y lanzar errores. |
| build | Comando del CLI que construye o empaqueta el proyecto. |
| deploy | Comando del CLI que publica o despliega el proyecto. |
| test | Comando del CLI que ejecuta pruebas. |
| run | Comando del CLI que ejecuta el programa o script principal. |
| clean | Comando del CLI que elimina archivos generados o temporales. |
| status | Comando del CLI que muestra el estado actual del proyecto o entorno. |
| logs | Comando del CLI que muestra registros o salidas de ejecución. |
| help | Comando del CLI que muestra ayuda o documentación de uso. |
| version | Comando del CLI que muestra la versión instalada del programa. |
