# Uso del Playground Interactivo

El Playground interactivo de GitHub Pages permite probar y ejecutar funcionalidades del proyecto de manera visual e interactiva directamente desde el navegador.

## ¿Qué es el Playground?

Es una interfaz web que permite experimentar con las funciones del sistema sin necesidad de ejecutar código localmente. Facilita pruebas rápidas y visualización de resultados.

## Cómo usarlo

1. Accede al enlace del Playground una vez publicado en GitHub Pages.
2. Selecciona la funcionalidad que deseas probar.
3. Ingresa los datos requeridos en los campos correspondientes.
4. Ejecuta la simulación para ver los resultados en tiempo real.

## Ejemplo de uso

Por ejemplo, si el playground permite cálculos numéricos:

- Ingresa los valores: `a = 5`, `b = 10`
- Selecciona la operación: suma
- Resultado: `15`

## Requisitos

- Conexión a internet
- Navegador actualizado
- Acceso al enlace del Playground publicado
