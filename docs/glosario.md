# Glosario

| Término | Definición |
|---|---|
| Algoritmo | Secuencia de pasos lógicos y finitos para resolver un cálculo o problema, ya sea matemático o computacional. |
| Aproximación | Valor cercano al resultado matemático exacto, usado cuando el cálculo perfecto es muy complejo o imposible. |
| Bisección | Método para encontrar raíces que divide un intervalo a la mitad repetidamente hasta acercarse a la solución. |
| Coeficiente de determinación (R²) | Medida que indica qué tan bien un modelo de regresión explica los datos observados. |
| Convergencia | Situación en la que las respuestas de un algoritmo se acercan cada vez más a la solución correcta. |
| Cota de error | Límite máximo que indica qué tan alejada podría estar una aproximación del valor real. |
| Cuadratura de Gauss | Método numérico para aproximar integrales utilizando puntos y pesos seleccionados estratégicamente. |
| Derivada | Operación matemática que calcula la tasa de cambio de una función en un punto específico. |
| Descomposición LU | Técnica que factoriza una matriz en una matriz triangular inferior (L) y una matriz triangular superior (U). |
| Diferencia centrada | Aproximación de una derivada utilizando valores a ambos lados del punto de interés. |
| Diferencia dividida | Cociente que aproxima la tasa de cambio de una función usando dos o más puntos conocidos; es base del polinomio interpolante de Newton. |
| Divergencia | Situación en la que un algoritmo falla y sus resultados se alejan cada vez más de la respuesta esperada. |
| EDO (Ecuación Diferencial Ordinaria) | Ecuación que relaciona una función con sus derivadas respecto a una sola variable. |
| Error absoluto | Diferencia directa entre el valor matemático real y el valor aproximado. |
| Error de redondeo | Error introducido al representar números reales con una cantidad finita de dígitos en la computadora. |
| Error relativo | Error absoluto dividido por el valor real; permite interpretar el error de forma proporcional. |
| Error relativo aproximado | Estimación del error calculada a partir de dos iteraciones consecutivas de un método numérico. |
| Extrapolación | Técnica para estimar un valor que está fuera del rango de los datos conocidos. |
| Interpolación | Estimación del valor de una función en un punto desconocido usando puntos conocidos que lo rodean. |
| Iteración | Cada repetición de un ciclo de cálculo en un algoritmo; en métodos iterativos produce una nueva aproximación. |
| Matriz | Arreglo de números organizado en filas y columnas, útil para representar y resolver sistemas de ecuaciones. |
| Método de Runge-Kutta (RK4) | Método numérico de cuarto orden para aproximar soluciones de ecuaciones diferenciales. |
| Orden del método | Medida de la rapidez con la que disminuye el error al reducir el tamaño del paso. |
| Pivoteo | Técnica usada en matrices para intercambiar filas y evitar pivotes nulos o numéricamente inestables. |
| Precisión | Nivel de exactitud de un cálculo, usualmente relacionado con la cantidad de cifras correctas. |
| Raíz | Valor de `x` donde una función `f(x)` vale cero. |
| Redondeo | Proceso de reducir la cantidad de decimales de un número aproximándolo al valor más cercano. |
| Regresión | Técnica estadística utilizada para modelar la relación entre variables. |
| Régula falsi | Método para encontrar raíces en un intervalo donde la función cambia de signo, usando una recta para aproximar la raíz. |
| Sistema lineal | Conjunto de ecuaciones lineales que se resuelven de manera simultánea. |
| Spline | Función construida uniendo varios polinomios de bajo grado en distintos subintervalos de forma suave. |
| Spline cúbico | Método de interpolación que utiliza polinomios cúbicos por tramos para generar curvas suaves. |
| Tolerancia | Valor positivo pequeño que define cuándo una aproximación es suficientemente buena para detener un algoritmo. |
